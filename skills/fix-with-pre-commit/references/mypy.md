# mypy 修复参考

## 可自动 / 半自动修复

| 错误类型 | 说明 | 修复方式 |
|----------|------|----------|
| 缺少返回类型注解 | 函数未标注返回类型 | 补充 `-> None`、`-> str` 等注解；对复杂返回值可用 `-> Union[...]` 或 `-> Optional[...]` |
| 缺少参数类型注解 | 函数参数无类型 | 补充参数类型；`self` / `cls` 不需要注解 |
| `name-defined` | 变量 / 名未定义 | 检查是否遗漏 import 或拼写错误 |
| `override` | 子类方法签名与父类不一致 | 对齐参数类型与返回类型，或加 `# type: ignore[override]` |
| `redundant-cast` | 不必要的 `cast()` | 移除该 cast |

## 需人工判断

| 错误类型 | 说明 | 原因 |
|----------|------|------|
| `union-attr` | Union 类型上访问仅部分分支存在的属性 | 需理解业务逻辑确定应 `isinstance` 窄化还是重构类型 |
| `arg-type` | 参数类型不匹配 | 可能涉及接口变更或跨模块协调 |
| `assignment` / `var-annotated` | 赋值类型冲突或多余注解 | 需判断是否应改类型或改赋值逻辑 |
| `no-untyped-def` | 禁止无类型函数（strict 模式） | 涉及逐步迁移策略，非一律加注解能解决 |
